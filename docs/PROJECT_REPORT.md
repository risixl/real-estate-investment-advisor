
# REAL ESTATE INVESTMENT ADVISOR

## Predicting Property Profitability & Future Value

### 1. Executive Overview

The Real Estate Investment Advisor is an end-to-end
machine learning project designed to support property
investment analysis and valuation.

The proposed system combines data analysis,
predictive modelling, and interactive visualization
to help users evaluate residential properties.

### 2. Business Problem

Real estate investors often face difficulties in
evaluating property prices, location characteristics,
and potential long-term appreciation.

The project aims to develop a data-driven application
that supports investment decisions through predictive
analytics.

### 3. Project Objectives

1. Analyze Indian residential housing data.
2. Identify factors associated with property value.
3. Develop an investment classification model.
4. Develop a property valuation model.
5. Build an interactive Streamlit application.
6. Track model experiments using MLflow.

### 4. Technology Stack

- Python

- NumPy
- Matplotlib
